# Home-Sidechain

## Receiver v40

Curve-first sidechain receiver inspired by modern volume-shaper workflows, using the Home-series dark/cyan/violet theme.

UI concepts: 16 curve presets, editable 5-point shaper graph, Mix, Depth, Full/Low/High band processing, crossover, tempo-sync rate, A/B/C routing, Bypass, Test and Reset.

The Receiver accepts Home-Link and MIDI triggers simultaneously; the selected A/B/C link maps to the corresponding MIDI note for external routing.
